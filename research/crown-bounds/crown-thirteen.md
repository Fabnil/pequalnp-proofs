# Коронный граф \(13\times13\)

**Точный минимум в модели Desk равен 45 вентилям AND/OR.** Конструкция на 45 проверена в Lean. Ниже бюджет 44 исключён сведением к конечным системам и проверкой в Python и Z3. Lean проверяет нормализацию и следствие о двойном занулении при условии ранее полученной вычислительной границы для 11 входов. [Постановка L-meta-18818](https://pequalnp.com/desk/row?gap=L-meta-18818) · [Конструкция](CrownGridBounds.lean#L121) · [Леммы для бюджета 44](CrownThirteenFrontier.lean)

## Бюджет 31 для порога два

Бюджет 44 для коронного графа эквивалентен бюджету 31 для порога два на 13 входах. Для порога два на 11 входах доказана нижняя граница 27, для 12 входов из неё следует 29. Нормализация при бюджете 31 даёт два чтения каждого исходного входа и ровно шесть дополнительных чтений общих сигналов. Общих сигналов от четырёх до шести, каждый активен хотя бы на одном одиночном входе. Полный профиль невозможен. [Сведение к порогу](CrownThreshold.lean#L74) · [Граница для 11 входов](crown-eleven.md) · [Нормальная форма в Lean](CrownThirteenFrontier.lean)

Зануление любых двух исходных входов даёт порог два на 11 входах. Четыре удалённых чтения исчерпывают возможную экономию. Поэтому сохраняются все общие сигналы и все листья остальных входов. Каждый общий OR-сигнал перед первой общей формулой с AND равен дизъюнкции некоторого множества исходных входов. В этом множестве хотя бы три метки. Если меток меньше, зануление двух входов могло бы погасить весь сигнал. [Двойное зануление](CrownRestriction.lean#L192) · [Три активатора в Lean](CrownThirteenFrontier.lean#L31)

## Общие формулы из OR

Условные разрезы выходной формулы проверены для 2148 графов с кратностями с точностью до переименования сигналов. Они оставляют шесть независимых OR-сигналов с двумя чтениями каждого. Двенадцать исходных входов читаются по разу в двух разных общих формулах. Их двухэлементные профили образуют граф степени четыре на шести сигналах. Три пропущенных профиля образуют совершенное паросочетание. Тринадцатый вход \(z\) дважды читается прямо в выходе и даёт пустой профиль. Все 15 оставшихся конфигураций отличаются выбором паросочетания. [Перебор графов](crown13_profiles.py) · [Неравенство для условных разрезов](CrownConditionalCuts.lean)

Разобьём шесть сигналов на три пары из этого паросочетания. Формула выхода \(H_0\) при \(z=0\) отвергает каждую двухэлементную комбинацию из разных пар. Она принимает любое трёхэлементное множество сигналов, поскольку такое множество является объединением двух реализованных двухэлементных профилей. Если зафиксировать один сигнал в единицу, а его партнёра в ноль, ограничение \(H_0\) вычисляет порог два на четырёх сигналах других пар. Упаковка разрезов вынуждает читать каждый из них ровно дважды. При такой фиксации сохраняются все листья из других пар.

Рассмотрим максимальное поддерево \(H_0\), все листья которого принадлежат одной паре \(P\). Его родитель включает листья другой пары. При каждой из фиксаций \(P=(1,0)\) и \(P=(0,1)\) поддерево должно принять нейтральное значение для операции родителя. Иначе родитель становился бы константой и удалял листья другой пары. Поэтому поддерево вычисляет OR или AND обоих сигналов \(P\). В каждой паре нужны оба типа поддерева. Без AND добавление второго сигнала в уже активную пару не сможет переключить отвергаемую двухэлементную комбинацию в принимаемую тройку. Без OR добавление первого сигнала из третьей пары также ничего не изменит. Бюджет из двух чтений каждого сигнала даёт ровно два поддерева по два листа на пару, одно с AND и одно с OR.

При \(z=0\) ни один из двенадцати листьев общих сигналов не исчезает, поскольку они все требуются в \(H_0\). Каждое вырождающееся поддерево содержит только \(z\). Оно присоединено через OR, иначе зануление убрало бы и сохраняемого соседа. Поэтому при \(z=1\) результат равен \(H_0\) с максимум двумя подформулами, заменёнными на единицу. Он должен отвергать нулевой профиль и принимать все двенадцать профилей из двух разных пар, поскольку это пары исходных входов с \(z\).

Скрипт проверяет все 30 240 способов соединить шесть поддеревьев из пар бинарными AND и OR. На тестах для \(z=0\) остаётся 54 формулы. Для каждой проверены все варианты замены максимум двух её подформул на единицу. Ни один вариант не проходит тесты для \(z=1\). [Проверка выходной формулы](crown13_matching_output.py)

## Наличие общего AND

Нормализация даёт первый общий сигнал с AND, читающий два более ранних несравнимых OR-сигнала, которые активны вместе с ним на одном одиночном входе. Применим ограничения на профили, выведенные при анализе 11 входов. Для каждой метки указываются два места чтения, активные сигналы и доступные зависимости. После фиксации общих сигналов вес чтений оценивается неравенством для условных разрезов. Масштаб целочисленных весов равен \(2^{2+6}=256\). [Нормализация первого AND](CrownOrFrontier.lean) · [Неравенство](CrownFrozenCuts.lean) · [Вывод ограничений на профили](crown-eleven.md)

Рассмотрено 3070 целочисленных систем. Перебираются все допустимые кратности и графы со стрелками вперёд, сохраняя позицию первого общего AND. Граф исключается из повторного перебора только по явному переименованию внутри OR-префикса и внутри суффикса. У 3044 систем Z3 подтвердил несовместность при требовании двух активаторов в ранних OR-сигналах. Для остальных 26 использовано следствие двойного зануления. С требованием трёх активаторов все 26 систем несовместны. [Перебор и целочисленная проверка](crown13_profiles.py)

Таким образом, порог два на 13 входах требует ровно 32 вентиля. Индукционный шаг даёт нижнюю границу \(2n+6\) для порога при \(n\ge13\), а с учётом сведения коронный граф требует минимум \(3n+6\) вентилей. Для \(16\times16\) эта граница даёт 54. Дальнейший перебор исключает бюджет 54 и устанавливает точный минимум 55. [Индукционный шаг](CrownProduct.lean#L15) · [Доказательство для \(16\times16\)](crown-sixteen.md)
