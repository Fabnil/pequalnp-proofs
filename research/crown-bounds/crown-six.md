# Шесть корон и линейная нижняя граница

Для шести непересекающихся корон \(4\times4\) в модели `RepSizeAtMost` точный минимум равен **65**. Для произвольного \(k\ge2\) получаем нижнюю границу

\[
  s(k)\ \ge\ 10k-1+\left\lceil\frac{2k}{3}\right\rceil.
\]

Граница действует при произвольной глубине AND. Для \(k\ge5\) также справедливо \(s(k)\ge10k+5\). Взвешенный подсчёт даёт более сильную общую границу и точный минимум 77 для семи корон. [Семь корон](crown-seven.md) · [Схема на 65 в Lean](CrownBlocks.lean#L203) · [Транспонирование OR-графа](crown-demand.md#обращение-рёбер-or-графа)

## Насыщение промежуточных множеств

Работаем в обратной схеме после разрезания AND. Начальное множество позиций \(D(v)\) исходного порта заменяем результатом соответствующего правила, пока оно состоит из целой двухэлементной пары. Это сохраняет ответ с любым другим портом. После этого большие требования, которым нужны минимум три парные позиции в терминальном множестве \(F_v\), могут иметь только начала размера хотя бы три. Порт называется общим, если его начало также назначено порту другой физической стороны. У равных начал замены выполняются одинаково.

Пусть \(m\) промежуточных объединений не назначены портам ни одной стороны. Для выбранных общих портов рассмотрим вспомогательные множества, оставив только пригодные. Они не содержат назначенного неодиночному порту множества ни одной стороны, позиции одиночного порта или выхода. Их конусы состоят из таких же объединений и одиночных позиций. Обозначим объединение их поддержек через \(W\). Тогда \(|W|\le2m\). Большое общее начало — объединение двух промежуточных множеств либо одного множества и одной позиции \(x\), поскольку оба его неодноэлементных аргумента пригодны по несравнимости. В начале содержится максимум одна позиция вне \(W\).

Для каждого нужного теста с одним активным общим портом ни одна позиция одиночного порта не возникает в течение нормализации. Иначе общий порт соответствующей физической стороны принимал бы всех соседей того одиночного порта. Правило, сработавшее на таком одиночном входе, может дать только одиночную позицию или пригодное промежуточное множество. В самом деле, если результат содержит назначенное начало другого порта, нарушается несравнимость на одной из двух сторон. Если он содержит собственное начало, нарушается топологический порядок. Позиция выхода также исключена отрицательным одиночным тестом.

На выбранной стороне обозначим через \(B^*\) объединение непересекающихся четвёрок \(B\) партнёрских позиций полных блоков и троек \(U\) партнёрских позиций блоков с тремя одиночными портами. В \(B^*\) можно включить только те блоки, для которых считаются общие большие начала. Назовём эти позиции полезными. Ни одна из них не расходуется в вычислении при одном активном общем порте, поскольку её партнёр сам является позицией одиночного порта.

Оставим правила, которые могут срабатывать при одном активном общем порте. Достаточно оставить все правила с результатом в виде пригодного промежуточного множества либо одной разрешённой позиции. Для верхней оценки запускаем их из \(W\) или из \(W\cup\{x\}\), где \(x\) — разрешённая позиция вне \(W\). Эти начала доминируют над соответствующими фактическими началами при запуске с накоплением позиций. Можно игнорировать правила, чей результат целиком в \(W\), поскольку все позиции \(W\) уже даны. Таким образом, остаются только правила, каждое из которых даёт одну позицию вне \(W\), и ни одно не расходует полезную позицию.

Нормализуем старт \(W\) в этом сокращённом наборе правил. Положим \(a=|W\setminus B^*|\). Пусть \(V\) — множество появившихся полезных позиций вне \(W\) и \(v=|V|\). В конечном множестве остаётся не более \(a-2v\) вспомогательных позиций. Каждый полезный результат расходует две вспомогательные позиции, а остальные срабатывания тоже уменьшают их число.

Теперь рассмотрим старт \(W\cup\{x\}\). Можно сначала заменить \(W\) его терминальным множеством, затем добавить \(x\). Такая замена сохраняет присутствие полезных позиций, поскольку каждое локальное правило меняет только свои два аргумента и выдаёт более поздний результат, а полезные позиции никогда не расходуются. Если \(x\) полезна, она не запускает ни одного правила, так что вне \(W\) доступны лишь \(V\cup\{x\}\). Если \(x\) вспомогательна, она может начать вычисление только через свою парную позицию в терминальном множестве. Эта парная позиция также вспомогательна. Любое новое срабатывание удаляет хотя бы одну позицию, которой не было в терминальном множестве, и добавляет максимум одну. Поэтому появляется не более одной новой полезной позиции. Поскольку возможных таких первых партнёров максимум \(a-2v\), все полезные позиции, которые можно добавить вспомогательной внешней позицией, лежат в одном множестве \(E\) размера максимум \(a-2v\). [Лемма об одном добавленном входе в Lean](CrownDemand.lean#L151)

Итак, **существует набор \(K\subseteq B^*\) размера максимум \(|W|-v\), вне которого каждое терминальное множество общего порта имеет максимум одну полезную позицию**. Можно взять

\[
 K=(W\cap B^*)\cup V\cup E,\qquad |K|\le |W|-v.
\]

Если нужная тройка содержит позицию вне \(K\), она должна быть исходной полезной позицией \(x\), а две остальные позиции тройки должны лежать в \(W\cup V\). В частности, при всех четырёх общих требованиях полного блока \(B\) вне \(K\) может быть только одна позиция \(x\) этой четвёрки, и тогда \(B\setminus\{x\}\subseteq W\cup V\).

## Линейная граница

Положим \(d=s(k)+1-10k\). После упрощения обратная схема на минимальном исходном размере имеет \(h=2k+b\) объединений при \(b\le d\). Обозначим через \(S_R,S_C\) числа одиночных портов, через \(\delta=4k-S_R-S_C\) их недостачу. Число неодиночных портов равно \(4k+\delta\), а число неодиночных портов с необщим началом равно \(2b-\delta-2m\). Отсюда \(\delta\le2b-2m\).

В каждом полном блоке есть четыре порта с требованием тройки, а в блоке с тремя одиночными портами один. По сравнению с четырьмя на блок недостача таких требований не более \(3\delta\): отсутствие одного одиночного порта убирает три требования, а отсутствие двух и более убирает максимум четыре. Следовательно, общих больших требований не менее

\[
  4k-3\delta-(2b-\delta-2m)=4k-2\delta-2b+2m.
\]

На каждой стороне построим \(K\) для этих требований. Если в полном блоке общими являются \(q\) из четырёх портов с требованием тройки, для \(q=1,2\) нужны хотя бы две позиции \(K\) в \(B\). При \(q=3,4\) нужны хотя бы три, поскольку среди четырёх дополняющих троек с двумя фиксированными пропущенными позициями максимум две содержат только одну из них. Поэтому \(q\le \tfrac43|K\cap B|\). Отдельная требуемая тройка из блока с тремя одиночными портами занимает хотя бы две позиции \(K\), и та же оценка верна. Все группы одной физической стороны непересекающиеся, поэтому максимум общих требований на ней равен \(\tfrac43|K|\le\tfrac83 m\). Обе стороны вместе дают

\[
  4k-2\delta-2b+2m\le \frac{16m}{3},\qquad
  4k\le 6b-\frac{2m}{3}.
\]

Отсюда \(d\ge b\ge 2k/3\), что даёт заявленную границу.

## Пять промежуточных множеств не дают три полных блока

Пусть в трёх полных блоках одной ориентации все четыре большие требования общие. Предположим \(m\le5\) и обозначим через \(c\) число их четвёрок, в которых есть позиция вне \(K\). По доказанному, \(12-c\le |K|\le |W|-v\). Для каждой из этих \(c\) четвёрок три другие позиции лежат в \(W\cup V\).

Если все пригодные помощники — пары, \(|W|\le10\), так что \(c\ge2\). В четвёрке с позицией \(x\) вне \(K\) для трёх дополняющих троек, содержащих \(x\), соответствующие начала имеют вид \(H\cup\{x\}\). Нормализация \(H\) должна дать две остальные полезные позиции каждой тройки, поскольку добавление \(x\) не запускает новых правил. Из пары \(H\) можно получить терминальную пару лишь среди самих промежуточных пар: каждое промежуточное срабатывание потребляет обе её позиции и даёт максимум две. Значит, такой четвёрке нужны все три пары её остальных позиций. Две непересекающиеся четвёрки требуют не менее шести пар.

Если хотя бы один помощник имеет три позиции и больше, \(|W|\le9\). Тогда \(c=3\), \(v=0\) и \(|W|=9\). Девять остальных позиций лежат в \(W\), так что все его позиции полезны. При пяти объединениях и девяти исходных позициях имеется ровно одна тройка и четыре непересекающиеся пары. Иначе хотя бы два объединения читали бы ранее построенное множество и добавляли максимум по одной новой позиции вместо двух. Три требования, содержащие пропущенную позицию \(x\) одной четвёрки, нуждаются в трёх разных помощниках, содержащих две позиции её оставшейся тройки. Среди четырёх пар подходит максимум одна, а из больших есть только одна тройка. Таким образом, пять помощников невозможны.

## Шесть корон при бюджете 64

Нижняя граница \(10k+4\) даёт \(h\ge17\), так что нужно исключить \(h=17\). Пишем \(S_i=7+d_i\). Если \(d_i=0\), все объединения — пары, требующие не менее 36 назначений для неодиночных портов обеих сторон. В \(h=17\) имеется максимум 34. При минимуме \(d_i=1\) нет полных блоков, и блоков с тремя одиночными портами максимум три. Это следует из [одно-помощниковых ограничений](crown-five-exact.md#одна-сторона-с-dle2) и даёт максимум 15 одиночных портов вместо как минимум 16. При минимуме \(d_i=2\) ни одна ориентация не содержит двух полных блоков, полного вместе с блоком из трёх одиночных, либо трёх блоков по три. С двумя полными, одним или без полных сумма одиночных максимум 16, а надо минимум 18.

Значит, \(d_i\ge3\) и \(S_i\ge10\). Сторона с \(d_i=3\) содержит максимум один полный блок одиночных портов. Обозначим ориентацию через сторону её одиночных портов. Имеется шесть форм:

| \(S_R,S_C\) с точностью до обмена | Блоки с четырьмя и тремя одиночными портами |
| --- | --- |
| \(10,10\) | По одному полному и по две тройки в каждой ориентации |
| \(10,11\) | Один полный и две тройки против двух полных и тройки |
| \(10,12\) | Один полный и две тройки против трёх полных |
| \(11,11\) | По два полных и по тройке в каждой ориентации |
| \(11,12\) | Два полных и тройка против трёх полных |
| \(12,12\) | По три полных в каждой ориентации |

Действительно, при сумме 20 требуется два полных блока, по одному на сторону, а остальные четыре имеют по три порта. Сумма 21 даёт три полных, один на стороне с \(S=10\) и два с \(S=11\), оставляя три тройки. Сумма 22 даёт четыре полных в распределении \(1+3\) либо \(2+2\) и две тройки. При 23 нужны пять полных, которых не может быть при \(10,13\), поскольку эта первая сторона вмещает максимум один, а вторая максимум три. При \(11,12\) получаем пять полных и одну тройку. При 24 все полные, и числа \(S_i\) кратны четырём.

**Один полный блок и две тройки на стороне с \(d_i=3\).** Противоположной стороне доступны максимум \(3-m\) эксклюзивных начал для шести больших требований. При \(m\le1\) общих не менее трёх, что слишком много. При \(m=2\) из шести требований минимум пять общие. Если одна тройка эксклюзивна, нужны все четыре требования полного блока и вторая тройка на двух помощниках, что исключено. Иначе общими являются обе тройки и не менее трёх требований полного блока. Для двух пар максимум три из этих пяти можно дать начальными тройками, ещё одно может использовать начало размера четыре. Для вложенной тройки \(Q\) нужны две позиции \(Q\) в полном блоке и по одной в двух остальных тройках, что невозможно.

При \(m=3\) все шесть требований общие. [Разбор полного блока вместе с отдельно требуемой тройкой](crown-five-exact.md#по-полному-блоку-и-тройке-в-каждой-ориентации) даёт \(W\subseteq B\cup U\). Этот аргумент использует только пять общих требований выбранных групп. Применив его с \(U=U_1\) и с \(U=U_2\), получаем \(W\subseteq B\). Тогда ни одну из \(U_1,U_2\) получить нельзя, поскольку все позиции \(W\) полезны и не могут быть израсходованы, а в начале есть максимум одна позиция вне \(W\).

**Два полных блока и тройка на стороне с \(d_i=4\).** При \(m\le3\) уже восемь требований двух полных блоков невозможны по [разбору с максимум \(4-m\) эксклюзивными началами](crown-five-exact.md#два-полных-блока-против-полного-блока-и-тройки). При \(m=4\) эти восемь требований и отдельная тройка общие. [Разбор четырёх помощников для двух полных блоков](crown-five-exact.md#по-два-полных-блока-в-каждой-ориентации) даёт \(W\subseteq B_1\cup B_2\) и тем самым исключает тройку вне \(W\).

**По три полных блока в обеих ориентациях.** При \(m\le1\) число общих больших начал слишком велико. При \(m=2\) среди трёх полных можно выбрать два с минимум тремя общими началами в каждом, поскольку эксклюзивных максимум три. Это невозможно на двух помощниках. При \(m=3\) есть четыре общих начала одного блока и минимум три другого, поскольку эксклюзивных максимум два. Этот [случай исключён раньше](crown-five-exact.md#два-полных-блока-против-полного-блока-и-тройки). При \(m=4\) два полных блока обязательно целиком общие, поскольку эксклюзивное начало максимум одно. Они оставляют \(W\) внутри своих двух четвёрок и не позволяют получить ни одной тройки третьего. При \(m=5\) все начала общие, что исключено выше новым подсчётом насыщения.

Все формы при \(h=17\) невозможны. Следовательно, точный минимум для шести корон равен 65.

## Семь корон и граница \(10k+5\)

Для семи корон граница \(10k+4\) оставляет \(h\ge19\). Если \(h=19\), то \(S_i=9+d_i\). Значение \(d_i=0\) оставляет только пары и не менее 42 неодиночных портов при максимум 38 назначениях. При минимуме \(d_i=1\) нет полных блоков и есть максимум три блока по три одиночных порта, то есть не больше 17 одиночных при необходимых двадцати. При минимуме \(d_i=2\) те же ограничения, что для шести корон, дают максимум 18 одиночных при необходимых 22. Поэтому \(S_i\ge12\) и \(\delta=28-S_R-S_C\le4\).

- При \(\delta=4\) числа \(S_i\) равны двенадцати, оба \(d_i=3\) и максимум два полных блока всего. Тогда одиночных максимум \(3\cdot7+2=23\), а нужно 24.
- При \(\delta=3\) числа \(S_i\) равны двенадцати и тринадцати. Нужны четыре полных блока, по одному на стороне с \(d=3\) и три на другой. Остатки одиночных портов восемь и один не получаются из трёх ориентированных троек.
- При \(\delta=2\) нужно не менее пяти полных блоков. Числа \(S_i=12,14\) оставляют максимум один полный на стороне \(d=3\) и три на другой. При \(S_i=13,13\) с пятью полными остатки пять и один не получаются из двух троек. Значит, имеется шесть полных, по три каждой ориентации, и один блок \((1,1)\).
- При \(\delta=1\) нужно шесть полных. Числа \(12,15\) оставляют максимум четыре из-за стороны с \(d=3\). При \(13,14\) имеется по три полных, но одна тройка не даёт остатков один и два.
- При \(\delta=0\) числа \(S_i\) кратны четырём и равны двенадцати и шестнадцати. На стороне с \(S=12\) получаются три полных блока при \(d=3\).

В оставшейся форме обе стороны имеют \(d=4\) и по три полных блока. Тогда \(m\le4\). Этот случай уже исключён в последнем разборе для шести корон. Достаточно трёх полных блоков одной ориентации и не более \(4-m\) эксклюзивных начал. Следовательно, \(s(7)\ge75\). Верхняя граница 77 получается объединением трёх пар и одного блока. [Схема на 77 в Lean](CrownBlocks.lean#L213)

Итак, \(s(k)\ge10k+5\) для \(k=5,6,7\), а при \(k\ge8\) это следует из линейной границы.
