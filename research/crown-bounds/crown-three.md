# Три короны требуют 33 вентиля

Для трёх непересекающихся корон \(4\times4\) в модели `RepSizeAtMost` точный минимум равен **33**. Более общая нижняя граница для \(k\ge3\) таких корон равна \(10k+3\). Конструкция для трёх объединяет схему на 21 вентиль для первых двух корон со схемой на 11 для последней и добавляет один OR. [Конструкция в Lean](CrownBlocks.lean#L188) · [Термины и леммы об обратной схеме](crown-demand.md)

## Возможные профили при бюджете 32

Транспонируем граф после разрезания всех AND. Если исходная схема имеет не более 32 вентилей, для вычисления \(D(v)\) в обратной схеме остаётся не более девяти бинарных объединений. В источнике с двумя парными позициями заменяем их результатом соответствующего AND, пока начальное множество состоит из такой пары. Замены пользуются уже вычисленными множествами и сохраняют ответы при любых других активных портах. Теперь каждое назначенное порту двухэлементное множество терминально, а \(|F_v|\ge3\) требует \(|D(v)|\ge3\). Используем [эквивалентность замен и несравнимость](crown-demand.md#одиночные-порты-и-нормализация-их-множеств).

Меньше девяти объединений исключает прежняя граница. Обозначим через \(S_R,S_C\) числа одиночных портов, а через \(d_R=S_R-3,d_C=S_C-3\) числа объединений, не занятых назначенными множествами каждой стороны. В таблице записана пара чисел одиночных портов каждого блока, с точностью до перестановки блоков и обмена сторон.

| \(d_R,d_C\) с точностью до обмена | Три профиля |
| --- | --- |
| \((0,0)\) | \((2,0),(1,1),(0,2)\) или три \((1,1)\) |
| \((1,1)\) | \((3,0),(1,1),(0,3)\) |
| \((1,2)\) | \((4,0),(0,3),(0,2)\) |
| \((2,2)\) | \((4,0),(1,1),(0,4)\) |

Действительно, \(S_R,S_C\ge3\). Если одно \(d\) равно нулю, все объединения дают пары, и ни один блок не имеет трёх одиночных портов. Значит, в каждом блоке ровно два и \(S_R=S_C=3\). При положительных \(d_R,d_C\) в каждой стороне хотя бы четыре одиночных порта. При сумме восьми распределение по блокам \(3,3,2\) вынуждено, поскольку полный блок требует \(d\ge2\) на противоположной стороне. При сумме девяти получаем \(S_R,S_C\) равными четырём и пяти. Полный блок на стороне с четырьмя обязателен, потому что иначе каждый блок дал бы три на одной стороне. Оставшиеся пять дают \(3,2\).

При сумме десяти и \(S_R,S_C=4,6\) полный блок на стороне с четырьмя оставил бы два блока с тремя одиночными портами на другой стороне. Одно свободное объединение не может дать нужные две непересекающиеся тройки. При пяти на каждой стороне получаем два полных блока и один с профилем \((1,1)\), поскольку распределение \(4,3,3\) не даёт пяти с каждой стороны. При сумме одиннадцать полные блоки распределяются по одному на сторону, с тремя дополнительными портами на одной из сторон. При сумме двенадцать полных блоков на сторонах один и два. В обоих случаях сторона с четырьмя одиночными портами имеет \(d=1\) и встречает полный блок на другой стороне. Это исключено.

## Общие множества и блок с одной одиночной строкой и одним столбцом

Если строка и столбец имеют одно и то же начальное множество, они соответствуют одному сигналу. Для двух общих сигналов обмен физическими сторонами сохраняет ответ. Если все неодиночные множества общие, этот обмен сохраняет степени в подграфе неодиночных портов. Два одиночных порта разных сторон с одинаковой позицией также имеют одинаковые множества положительных соседей среди общих сигналов.

Пусть в блоке с профилем \((1,1)\) три неодиночные строки и три неодиночных столбца попарно объединены в три общих сигнала внутри блока. Спаривание идёт по диагонали, иначе одна и та же начальная активация давала бы положительный ответ с одним и с двумя портами. Каждый из трёх наборов \(F_v\) должен содержать обе парные позиции \(\alpha,\beta\) одиночной строки и столбца. Три набора попарно несравнимы и должны принимать все три взаимные пары.

Если \(\alpha=\beta=\gamma\), достаточно показать, что хотя бы два набора имеют размер два. Пусть это \(\{\gamma,x\}\) и \(\{\gamma,y\}\). Они терминальны. Партнёр позиции \(\gamma\) — одиночный порт, поэтому он не входит ни в один общий неодиночный набор по несравнимости окрестностей. Чтобы два набора вместе запустили первый AND, \(x,y\) должны быть парой его входных позиций. Чтобы \(\{\gamma,x\}\) дополнял третий терминальный набор до положительного теста, этому набору нужна позиция \(y\). Он уже содержит \(\gamma\), и потому сравним со вторым набором. [Лемма о двух парах в Lean](CrownDemand.lean#L82)

## Исключение пяти профилей

### Все объединения назначены на обеих сторонах

При \(d_R=d_C=0\) все девять неодиночных множеств — общие терминальные пары. У неодиночных строк каждого блока граф общих неодиночных соседей связен. Для профиля \((1,1)\) любые две из трёх строк имеют общего соседа. Для \((2,0)\) две строки имеют двух общих соседей среди четырёх столбцов. Для \((0,2)\) две строки степени два имеют оба столбца в соседях и соединяют две оставшиеся строки степени один. Поэтому спаривание переводит неодиночные строки одного блока в столбцы одного блока. То же верно при обмене сторон, так что соответствие блоков — перестановка. По симметрии любой положительной клетки эта перестановка — инволюция. На трёх блоках имеется неподвижный блок, и он обязан иметь профиль \((1,1)\), поскольку число неодиночных строк должно совпадать с числом столбцов.

В неподвижном блоке три пары \(F_v\) должны содержать \(\alpha,\beta\). Если они различны, все три совпали бы. Если равны, действует лемма о двух парах.

### Полный блок и три одиночных порта в другой ориентации

Для \((4,0),(0,3),(0,2)\) сторона строк имеет \(d_R=1\). Три одиночных столбца требуют хотя бы одной конечной тройки, поэтому единственный пригодный помощник на стороне строк — пара \(P\). Каждая конечная тройка строк содержит \(P\). Сторона столбцов назначает семь объединений, сторона строк восемь, так что общих не менее шести из девяти. Среди четырёх неодиночных столбцов полного блока хотя бы три общих. Их \(F_v\) имеют размер хотя бы три и должны дать три разные дополняющие тройки одной четвёрки, все содержащие \(P\). Одна пара входит максимум в две такие тройки.

### По три одиночных порта в каждой ориентации

Для \((3,0),(1,1),(0,3)\) каждой стороне нужно по конечной тройке. Поэтому единственное неназначенное объединение каждой стороны — пригодная пара. Если эти пары различны, две стороны имеют по одному эксклюзивному множеству и оба — пары. Каждая тройка тогда общая и содержит пару, назначенную порту другой стороны, что нарушает несравнимость. Значит, пригодная пара \(P\) общая для вычислений обеих сторон и все восемь неодиночных множеств общие. Пара \(P\) лежит в обеих тройках партнёрских позиций блоков с тремя одиночными портами.

Три неодиночных порта блока \((1,1)\) на каждой стороне имеют степень два среди неодиночных. В других блоках встречаются только степени ноль, один и три. Поэтому три сигнала спариваются внутри блока \((1,1)\). Его \(\alpha,\beta\) лежат вне \(P\): каждая принадлежит собственному одиночному порту той же стороны, что и три одиночных порта, чьи партнёрские позиции содержат \(P\). Если \(\alpha\ne\beta\), терминальная пара обязана быть \(\{\alpha,\beta\}\), а тройка не вместит ещё \(P\). Если \(\alpha=\beta\), из трёх терминальных наборов максимум один является тройкой \(P\cup\{\alpha\}\), и ни один не одноэлементный по несравнимости. Это снова даёт два набора размера два.

### По полному блоку в каждой ориентации

Для \((4,0),(1,1),(0,4)\) каждая сторона назначает семь объединений из девяти. Пусть \(m\) — число общих множеств. Тогда \(5\le m\le7\) и неназначенных на обеих сторонах объединений ровно \(m-5\). Каждая сторона имеет четыре больших начала для полного блока и три прочих. Следовательно, хотя бы \(m-3\) общих начал дают дополняющие тройки полного блока. Общие начала могут использовать только объединения, неназначенные на обеих сторонах. По несравнимости это верно и при их одиночной нормализации.

При \(m=5\) большие общие начала вычислить невозможно. При \(m=6\) один помощник даёт максимум две дополняющие тройки, а нужны хотя бы три. Остаётся \(m=7\). Все неодиночные множества спарены. Три сигнала блока \((1,1)\) спариваются внутри него, поскольку только они имеют ненулевую степень среди неодиночных портов. Его \(\alpha,\beta\) отличаются от партнёрских позиций обоих полных блоков. Иначе одиночный порт блока \((1,1)\) и одиночный порт полного блока имели бы одинаковых соседей среди общих сигналов. Их положительные множества непусты и лежат в разных группах сигналов.

Неназначенных объединений два. Если оба — пары, обе лежат в четвёрке партнёрских позиций одного из полных блоков. Одна пара даёт максимум две дополняющие тройки, а одно начало размера четыре добавляет максимум ещё одну. Если помощники — вложенные пара и тройка, тройка лежит в четвёрке полного блока по [разбору вложенных множеств](crown-demand.md#два-промежуточных-множества). Поэтому все позиции помощников полезны для одиночных портов полного блока. Они не расходуются при нормализации общего множества, поскольку их партнёры сами одиночные порты. Любое большое общее начало состоит из одного или двух помощников и содержит максимум одну дополнительную позицию. Поэтому оно терминально. Пары уже выбраны терминальными.

Если \(\alpha,\beta\) различны, три множества блока \((1,1)\) не могут содержать обе: большие имеют максимум одну позицию вне помощников, а возможная пара единственна. Если \(\alpha=\beta=\gamma\), большой набор этого блока обязан состоять из полезных позиций помощника и \(\gamma\). Все его позиции парны к одиночным портам и потому при добавлении к другому терминальному неодиночному набору не запускают ни одного правила. Это противоречит положительным клеткам между тремя общими сигналами. Следовательно, остаются только пары, что также невозможно.

Все профили при девяти объединениях исключены. Итак, трём коронам нужны 33 вентиля.

## Граница \(10k+3\) для \(k\ge4\)

Осталось исключить \(h=2k+3\), поскольку \(h\le2k+2\) уже исключено. Сохраняем \(\delta=4k-S_R-S_C\). Вариант только с парами невозможен, так как \(6k>4k+6\). Следовательно, \(1\le d_R,d_C\) и \(d_R+d_C=6-\delta\), так что \(\delta\le4\). Физическая сторона с \(d=1\) не может содержать неодиночные порты полного блока. При \(d=2\) она не может содержать их в двух полных блоках, либо в полном блоке и ещё в блоке с тремя одиночными портами.

- Если \(\delta=1\) и \(d=1\) на одной стороне, все \(k-1\) полных блоков имеют одиночные порты на ней, но \(S=2k-2<4(k-1)\). При \(d_R,d_C=2,3\) сторона с \(d=3\) имеет максимум один полный блок одиночных портов и максимум семь одиночных портов всего. Нужно \(S=2k\ge8\).
- Если \(\delta=2\) и есть сторона с \(d=1\), она вмещает все \(k-2\) полных блоков одиночных портов, но \(2k-2<4(k-2)\) при \(k\ge4\). При \(d_R=d_C=2\) полных блоков максимум два, значит, остаётся лишь \(k=4\).
- При \(\delta=3\) есть сторона с \(d=1\) и другая с \(d=2\), поэтому полный блок максимум один. Значит, \(k\le4\).
- При \(\delta=4\) обе стороны имеют \(d=1\), полных блоков нет и \(k\le4\).

Случаи \(k=4\) с \(\delta>0\) исключены в [доказательстве для четырёх корон](crown-demand.md#необходимая-форма-для-42-вентилей). Если \(\delta=0\), обе ориентации полных блоков встречаются, иначе \(N=4k>h\) на одной стороне. Если одно \(d=2\), другой стороне с \(d=4\) доступен только один полный блок одиночных портов, а нужно \(S=2k+1>4\). Поэтому \(d_R=d_C=3\), \(N_R=N_C=2k\), и с каждой стороны не менее двух полных блоков.

Заключительный разбор для четырёх корон теперь применяется к любым двум полным блокам на одной стороне. После выбора больших начал для всех неодиночных портов есть \(2k-3+m\) общих начал, где \(m\le3\) — число объединений, неназначенных ни одной стороне. При одном помощнике можно получить максимум две нужные тройки, при двух парах максимум пять. При вложенных паре и тройке один из двух выбранных блоков встречает тройку максимум в одной позиции. Это допускает максимум два общих начала в этом блоке, а при \(m=2\) общих не менее трёх в каждом блоке. Следовательно, \(m=3\) и все начала общие. Три пары помощников и случай с большим помощником исключаются [подсчётом для двух непересекающихся четвёрок](crown-demand.md#исключение-трёх-промежуточных-множеств). Отсюда \(h\ge2k+4\) и \(s(k)\ge10k+3\).

## Оценка для больших \(k\)

Для \(k\ge2\) положим \(d=s(k)+1-10k\). Тогда

\[
  4k\le 5d^2-d,\qquad
  s(k)\ \ge\ 10k-1+\left\lceil\frac{1+\sqrt{1+80k}}{10}\right\rceil.
\]

Действительно, пусть в обратной схеме после удаления повторов \(h=2k+b\) объединений. Тогда \(2\le b\le d\) по прежней границе. Заменяем двухэлементные начала с парными позициями на эквивалентные, как в начале доказательства. При одинаковых начальных множествах двух портов выбор одинаков. Как и раньше, \(N_R+N_C=4k+\delta\), где \(\delta=4k-S_R-S_C\). Пусть \(m\) объединений не назначены ни одной стороне. Тогда \(m\le b\), и число неодиночных портов с множеством, назначенным только одной стороне, равно \(2b-\delta-2m\). Полных блоков не меньше \(k-\delta\), и каждый полный блок с необщим неодиночным портом расходует хотя бы один такой порт. Значит, есть хотя бы \(k-2b+2m\) полных блоков, у которых все четыре неодиночных порта общие. На одной физической стороне находятся \(r\) таких блоков, где \(4r\ge2(k-2b+2m)\).

Каждое из \(4r\) начал должно иметь размер хотя бы три и строится из двух промежуточных множеств \(H,H'\) либо из \(H\) и одной позиции \(x\). Пригодных промежуточных множеств не больше \(m\). Они не содержат множеств, назначенных неодиночным портам хотя бы одной стороны, и поэтому сами строятся из одиночных позиций и других пригодных множеств. Их объединение \(W\) содержит не более \(2m\) исходных позиций. Начал вида \(H\cup H'\) не более \(\binom m2\).

Зафиксируем \(H\), входящее в некоторое начало \(H\cup\{x\}\). Его нормализация в \(F(H)\) может выдавать неодноэлементные множества только из числа пригодных помощников. Правило, сработавшее при \(H\), сработало бы и при содержащем его общем начале. Это следует из монотонности обычного запуска, который только добавляет позиции. Поэтому результат такого правила не может содержать назначенное множество ни одной стороны. Вне \(W\) правило может выдать только одну позицию. Если при нормализации \(H\) израсходовано \(c\) позиций внутри \(W\) и \(u\) вне \(W\), произошло \((c+u)/2\) срабатываний. Значит, в \(F(H)\) не более \((c+u)/2-u\) позиций вне \(W\) и не более \(|W|-c\) внутри. В итоге \(|F(H)|\le |W|\le 2m\).

Пусть \(B^*\) — объединение непересекающихся четвёрок \(B\) выбранных полных блоков. При добавлении \(x\) к \(F(H)\) новое правило может сработать только при наличии парной к \(x\) позиции в \(F(H)\). Для \(x\) из общего начала эта парная позиция не может лежать в \(B^*\). Иначе \(x\) совпал бы с позицией одиночного порта и нарушил бы несравнимость на одной из двух физических сторон. Поэтому таких \(x\) не более \(|F(H)\setminus B^*|\).

Для остальных \(x\) множество \(F(H)\cup\{x\}\) уже терминально. Если в четвёрке \(B\) исходно меньше двух позиций \(F(H)\), ни один такой \(x\) не даст трёх соседей. Если таких позиций две, подходят максимум две позиции \(x\) из \(B\). Если их три, без добавления четвёртой позиции возможен только порт с соответствующей дополняющей тройкой, а добавление четвёртой позиции даёт одно начало. При четырёх позициях возможны максимум четыре порта блока. Во всех случаях число таких начал для \(B\) не превышает \(|F(H)\cap B|\). Суммируя по блокам и прибавляя \(x\), которые запускают правило, получаем максимум \(|F(H)|\le2m\) начал на помощник.

Следовательно, \(4r\le2m^2+\binom m2\), и

\[
  4k\le5m^2-9m+8b\le5b^2-b\le5d^2-d.
\]

Для среднего перехода используем \(0\le m\le b\) и \(b\ge2\). Эта оценка усиливает \(10k+3\) при \(k\ge20\).
